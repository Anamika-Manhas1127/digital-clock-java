# Digital Clock using Java

## About the Project
This is a simple Digital Clock application developed using Java. It displays the current time in hours, minutes, seconds, and AM/PM format. The clock updates automatically every second.

## Features
- Displays the current system time.
- Shows hours, minutes, and seconds.
- Supports AM/PM time format.
- Updates the displayed time automatically every second.
- Simple desktop graphical user interface.

## Technologies Used
- Java
- Java Swing
- Java AWT
- Java Time API

## How to Run the Project

1. Install the Java Development Kit (JDK) on your computer.
2. Download or clone this repository.
3. Open the project in Visual Studio Code or another Java IDE.
4. Compile and run `Main.java`.

### Using the Terminal

```bash
javac Main.java
java Main
```
